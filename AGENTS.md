# Project Instructions

- Implement Logscope in Python 3 using only the standard library unless a dependency is explicitly approved.
- Keep log processing streaming; do not read an entire log file into memory.
- Use `unittest` and run the relevant tests after every implementation change.
- Keep parser, command logic, rendering, and CLI argument handling separately testable.
- Preserve malformed-line resilience: count and skip invalid lines.
- Do not create commits. Ask for explicit permission before every manual file creation or edit.
- Do not implement the LLM stretch goal unless explicitly requested after the core tool is complete.
